Мои компетенции

Frontend

Лендинги, дашборды и веб-приложения. HTML/CSS с Tailwind, TypeScript, React для сложных интерфейсов — и чистый Vanilla JS там, где его хватает. Адаптив от 320px, анимации на GSAP, 3D на Three.js.

Backend & Automation

Python (FastAPI) и Node.js для серверной части. Telegram-боты и Mini Apps, базы данных (PostgreSQL, SQLite), парсеры, автоматизация. Интеграции с внешними API и платёжными системами.

Apps & Infra

Git и GitHub для версионирования, Docker для изоляции окружения, GitHub Actions для CI/CD. Деплой на Linux VPS через Nginx или на Vercel. От нуля до рабочего продакшна.

3D-сайт

Meridian Noir

Three.js · WebGL GSAP Lenis TypeScript

Задача

Сайт уровня Awwwards для вымышленного парфюмерного дома, и ни одного файла изображений. В центре работающие солнечные часы, а гномон в них — 3D-флакон, построенный кодом. Сайт должен плавно идти на телефоне и одинаково хорошо смотреться на десктопе и на iPhone.

Что сделано

Солнечные часы с настоящим астрономическим расчётом для пяти площадок в обоих полушариях. Флакон написан кодом: гранёное стекло, настой с колыханием, помпа, этикетка и тень от стекла. Шесть сцен срежиссированы прокруткой, пять формул переключаются с перетеканием дня, а флакон крутится пальцем, не блокируя прокрутку.

Сколько это примерно стоит?

230 000 – 450 000 ₽

Своя графика в реальном времени — верхний сегмент промо-сайтов: флакон и солнечные часы пишутся кодом вместо съёмки, плюс адаптив от телефона до 4K, доступность и запасные версии.

3D-презентация

Keyboard Showcase

Three.js · R3F React GSAP TypeScript

Задача

Сайт-презентация премиальной механической клавиатуры с настоящим 3D в браузере, на уровне продуктовых страниц Apple. Продукта физически не существует, поэтому модель, материалы и фирменный стиль нужно было придумать и собрать с нуля.

Что сделано

Клавиатура целиком построена кодом на React Three Fiber: семь слоёв, 68 клавиш, процедурные текстуры платы, ни одной сторонней модели. Вся сцена — чистая функция от прокрутки, поэтому идёт одинаково плавно вперёд и назад. Мобильная версия разворачивает композицию под портрет и снимает нагрузку по тому, чего на экране в ладонь всё равно не видно.

Сколько это примерно стоит?

150 000 – 450 000 ₽

Процедурная 3D-сцена со скролл-анимацией — верхняя планка веб-разработки: геометрия, материалы и пост-обработка пишутся руками.

Программа для Windows

SmartySorter

Python pywebview Windows .exe

Задача

Десктопный сортировщик файлов для Windows — с приятным интерфейсом, гибкой настройкой категорий и без единого стороннего фреймворка на фронте.

Что сделано

Бэкенд на Python в связке с pywebview — нативное окно вместо Electron. Сортировка по категориям в один клик, полноценный undo с восстановлением структуры папок, защита от перезаписи при конфликте имён, редактируемые категории расширений, локализация на 3 языка и тёмная/светлая тема с синхронизацией с ОС.

Сколько это примерно стоит?

5 000 – 25 000 ₽

Десктоп дороже веба на сборке и тестах: собрать .exe, проверить на разных версиях Windows и сделать все операции с файлами отменяемыми.
